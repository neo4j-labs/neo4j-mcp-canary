## v0.4.1 - 2026-09-10
### Fixed
* HTTP mode: register GDS tools and perform first-connection verification on the modern stateless "discover" handshake (protocol version 2026-07-28+, negotiated by default since the mark3labs/mcp-go v1.0.0 upgrade), not just the legacy "initialize" handshake. Previously only the legacy path triggered verifyRequirements/addGDSTools via the OnBeforeInitialize hook, so any client that negotiated the modern protocol (the default for mcp-go v1.0.0 clients) silently skipped connectivity verification, GDS tool registration, and the connection-initialized analytics event.
### Security
* Upgrade Go toolchain to 1.26.6 to address CVEs in the earlier Go version, and bump mark3labs/mcp-go v0.58.0 -> v1.0.0, neo4j-contrib/query-go-sdk v0.5.0 -> v0.6.0, plus transitive dependency updates.
